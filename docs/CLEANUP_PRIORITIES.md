## 删除门槛

任何旧文件只有在同时满足以下条件后才能删除：

1. 已有SHA256；
2. 已确认不是唯一原始数据；
3. 已确认不被正式脚本和文档引用；
4. 已存在另一份可读取副本或明确判定为可再生缓存；
5. 删除清单经过人工确认。
