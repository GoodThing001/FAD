## 2. :red_circle: 关键修正：SHGR 排名 ≠ 独立增量

v10 实验对 NUPACK 17 个子块做了独立 30-seed 验证（每个子块单独 + 序列 303d），结果与之前 SHGR 重要性排名**严重不一致**：

| NUPACK 子块 | SHGR 排名 | SHGR 得分 | **独立增量 Δ** | 真相 |
|---|---|---|---|---|
| squarna（SQUARNA 茎） | 第 1 | 0.831 | **-0.004** | :x: 有害（假象） |
| pos_pair_prob（配对概率） | 第 2 | 0.778 | **+0.005** | :white_check_mark: 真有用 |
| motif（5-Motif） | 第 3 | 0.759 | **+0.005** | :white_check_mark: 真有用（需拆位点级/全局） |
| mfe（MFE 结构） | 第 4 | 0.782 | -0.005 | :x: 有害 |
| **contact_pca（接触 PCA）** | 第 5 | 0.747 | **+0.012** | :trophy: 最有价值 |

**:bulb: 为什么 SHGR 会误判（squarna 假象）**：SHGR 重要性是在**全量 1192d 特征**上，由 tree 模型"选中"哪些特征用于分裂。但 tree 模型会"借用"相关性高的特征——某个特征可能因为与另一个真信号特征高度相关而被选上，但它本身没有独立信息量。**独立增量（单独加该子块的提升）才是真正有用的标准。**

**:bulb: 为什么 motif 之前被误判为无用**：v10 第一次验证把 motif 的**位点级（78d）和全局（42d）混在一起**（共 120d），整体 Δ=-0.000。v10b 拆开后发现两者各有正增益（位点级 +0.0046，全局 +0.0051）。**"混合掩盖了信号"**——这是与"全量 NUPACK 无效"相同的问题：有用的子块和噪声子块混在一起。

## 3. 有用 NUPACK 子块的详细计算

### 3.1 contact_pca（接触矩阵 PCA）— 15d :trophy: 最有价值

**怎么得到**: NUPACK 配对概率矩阵 (141×141) → 特征值分解。

**怎么算**:
```python
bp_probs = nupack.pairs(...).to_array()  # (141,141) 配对概率矩阵
eigvals = np.linalg.eigvalsh(bp_probs)    # 特征值（升序）
eigvals_desc = eigvals[::-1][:10]          # 取前 10 大

feats["contact_eig_%d" % k] = eigvals_desc[k]           # 10d
feats["contact_spectral_gap"] = eigvals_desc[0] - eigvals_desc[1]  # 谱间隙
feats["contact_trace"] = np.trace(bp_probs)             # 迹
feats["contact_top1_var"] = eigvals_desc[0] / sum       # 主模态方差占比
feats["contact_top3_var"] = sum(eigvals_desc[:3]) / sum
feats["contact_top5_var"] = sum(eigvals_desc[:5]) / sum
```

**为什么有用**: 配对概率矩阵的特征值谱反映**RNA 折叠的确定性程度**。若 λ₀ 占主导（top1_var 高），序列折叠为单一确定结构；若特征值分散，结构模糊、存在多个竞争构象。gbsa（结合自由能）与折叠确定性相关——**折叠确定的序列，其三级结构更稳定、结合更一致**。

**实验结果**: +0.012（30-seed，所有 NUPACK 子块中最大增益）。

### 3.2 cluster_pair（簇间/簇内配对）— 7d :white_check_mark:

**怎么得到**: 突变簇（P2 茎 / L2 环 / P3 茎）两两之间的配对概率之和。

**怎么算**:
```python
MUT_CLUSTERS = {0: [30,31,32,33], 1: [89,90,91,92], 2: [127,128,129,130,131]}
# 簇间: 3 个簇对 (0,1),(0,2),(1,2) 的配对概率之和
for (ca, cb) in [(0,1),(0,2),(1,2)]:
    inter = sum(bp_probs[pa-1, pb-1] for pa in cluster[ca] for pb in cluster[cb])
# 簇内: 3 个簇各自内部的配对概率之和
# 长程: >20nt 的配对计数
```

**为什么有用**: 突变簇之间的配对关系直接反映"突变是否跨越簇产生了新的长程相互作用"。跨簇配对是 RNA 三级结构的特征，与 gbsa 相关。

**实验结果**: +0.006。

### 3.3 energy_land（能量景观）— 5d :white_check_mark:

**怎么得到**: 从配对概率矩阵的稳定性分布计算。

**怎么算**:
```python
feats["n_very_stable_pairs"] = 配对概率>0.9 的对数
feats["n_moderate_pairs"]    = 配对概率>0.5 的对数
feats["stable_pair_ratio"]   = 稳定对 / 中等对
feats["eig_ipr"]             = 特征值 IPR（~1 单模态，~1/N 均匀）
feats["eig_n_eff_modes"]     = 有效模态数 = 1/IPR
```

**为什么有用**: 与 contact_pca 类似，反映折叠确定性。IPR（inverse participation ratio）量化"有多少个竞争构象"。

**实验结果**: +0.006。

### 3.4 pos_entropy（位点结构熵）— 13d :white_check_mark:

**怎么得到**: 每个突变位点的结构熵。

**怎么算**:
```python
# H = -p·log2(p) - (1-p)·log2(1-p)
for pos in MUT_POS:
    p = pos_pair_prob[pos-1]  # 该位点配对概率
    H = -(p*log2(p) + (1-p)*log2(1-p))
    feats[f"pos{pos}_entropy"] = H
```

**为什么有用**: 熵量化该位点的"配对不确定性"。熵=0 表示确定配对或确定不配对；熵=1 表示完全不确定（50% 配对概率）。位点结构不确定性影响三级折叠稳定性。

**实验结果**: +0.005。

### 3.5 pos_pair_prob（位点级配对概率）— 32d :white_check_mark:

**怎么得到**: 每位点与任何位点配对的总概率。

**怎么算**: 见 [特征整理_v2.md](特征整理_v2.md) §2.3 的修正部分。

**为什么有用**: 比 structure_role（离散 0/1）更精细的连续量，直接反映"突变后该位点是否还倾向于配对"。

**实验结果**: +0.005。

### 3.6 motif_positional（位点级模体分类）— 78d :white_check_mark:

**怎么得到**: 从 MFE 结构的 dot-bracket 解析每个突变位点的结构模体类型。

**怎么算**:
```python
MOTIF_NAMES = ["S", "H", "I", "B", "M", "E"]  # Stack/Hairpin/Interior/Bulge/Multi/External
# Step 1: 解析 dot-bracket 得到配对关系
# Step 2: 识别连续配对形成的螺旋（helix stack）
# Step 3: 标记茎区位置为 S（Stack）
# Step 4: 根据环连接几个茎，分类为 H（发夹）/ B（凸起）/ I（内环）/ M（多分支环）
# Step 5: 每个突变位点 6 维 one-hot（属于哪种模体）
for pos in MUT_POS:
    m = motif_per_pos[pos-1]  # S/H/I/B/M/E
    feats[f"motif_pos{pos}_is_{m}"] = 1.0
# 13 位点 × 6 类 = 78d
```

**为什么有用**: 比 structure_role（茎/环二分法）更精细的结构分类。区分"发夹环"和"内环"——不同类型的环对 RNA 折叠稳定性的影响不同。位点级模体类型直接编码了突变位点的精确结构上下文。

**实验结果**: +0.005（v10b 拆分后确认）。

### 3.7 motif_global（全局模体统计）— 42d :white_check_mark:

**怎么得到**: 统计整条序列（236nt）和适配体区（141nt）各模体类型的数量、比例、片段长度。

**怎么算**:
```python
# 全局（236nt）: 每类模体的数量 n、比例 frac、平均片段长度 avg_len、最大长度 max_len、片段数 n_segments
# 适配体（141nt）: 每类模体的数量 n、比例 frac
# 6 类 × (5 全局 + 2 适配体) = 42d
```

**为什么有用**: 模体的全局分布反映序列整体的折叠复杂度。虽然 128/141 位置固定，但 13 个突变位点的变化会通过结构重排影响全局模体分布，因此全局统计仍含突变诱导的信号。

**实验结果**: +0.005（v10b 拆分后确认）。

## 6. 结论

1. **SHGR 重要性排名不可信** — 它衡量"全特征上被选中"，而非"独立有信号"
2. **真正有用的 NUPACK 子块共 7 个，合计 192d**（contact_pca / cluster_pair / energy_land /
   pos_entropy / pos_pair_prob / motif_positional / motif_global）
3. **contact_pca（15d）是意外之喜** — 增益 +0.012，维度最小，物理意义明确（折叠确定性）
4. **squarna 无用** — 之前 SHGR 排名第 1 是假象；**motif 在 v10b 按位点级/全局拆分后
   确认均有用**（位点级 +0.0046、全局 +0.0051），早期「motif 无用」结论已被推翻
5. **核心特征集 ~495d**（303d 序列 + 192d NUPACK 有用子块），全部秒级可算，适合代理优化
6. **下一步**: 验证 192d 组合的叠加增益（→ v11 已完成，见 §5.3 补注）
