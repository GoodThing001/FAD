### 2.3 实验 1C: rank-target 回归（rank-uniform / rank-Gaussian / winsorized）

**目的**: 当前 gbsa 有右偏和极端值（max=109 vs mean=26），MSE 过度关注极端值。rank 变换让模型聚焦于排序而非数值。

**四种目标形式**:

| 目标 | 公式 | 适用模型 |
|---|---|---|
| raw（基线） | 原始 gbsa | RF/ET（对照） |
| rank-uniform | `(rank(y)-0.5)/n` — 均匀秩 | RF/ET/GBR/XGB |
| rank-Gaussian | `Φ⁻¹((rank(y)-0.5)/n)` — 正态秩 | SVR/GBR/XGB |
| winsorized 2.5% | 裁尾到 [P2.5, P97.5] | 全模型 |

**rank-Gaussian 折内实现**:

```python
import numpy as np
from scipy.stats import rankdata, norm

def fit_rank_gaussian(y_train: np.ndarray) -> np.ndarray:
    """只能在训练折标签上调用。"""
    n = len(y_train)
    q = (rankdata(y_train, method="average") - 0.5) / n
    q = np.clip(q, 1e-4, 1 - 1e-4)
    return norm.ppf(q).astype(np.float32)
```

**步骤**:

```bash
python scripts/tools/eval_rank_targets.py \
  --targets raw,rank_uniform,rank_gaussian,winsor_2.5 \
  --losses mse,mae,huber \
  --features mutation_only,mut_struct_wd,mut_struct_wd_ed \
  --models RF,ET,SVR,GBR,XGB \
  --outer-seeds 30 --inner-folds 5 \
  --screen-k 50,75,100 \
  --output artifacts/phase1_v8/rank_targets_30seed.csv
```

**成功判定**: rank-Gaussian + SVR 或 rank-uniform + RF 的平均 ΔSp ≥ 0.005。

## 4. Phase 3: OOF 秩融合与 bagging（Week 3–4）:arrow_forward: 当前

### 4.1 实验 3A: 严格 OOF 秩融合

**目的**: 利用不同模型的误差互补。关键是融合权重必须在内层 OOF 上优化，不在外层测试集上选择。

**融合池**:

| 成员 | 特征 | 模型 | 目标 | 异质性来源 |
|---|---|---|---|---|
| M1 | mutation_only | RF | rank-uniform | Bagging + 低维 |
| M2 | mutation_only | ET | rank-uniform | 不同树结构 |
| M3 | mut+struct+wd | SVR | rank-Gaussian | 核方法 + 不同特征 |
| M4 | mut+struct+wd | GBR | rank-Gaussian | Boosting |
| M5 | mut+struct+wd+ED (折内) | RF | rank-uniform | 全特征 |
| M6 | mut+struct+wd+ED (折内) | SVR | rank-Gaussian | 核+全特征 |

**融合方法**:

```
1. 等权秩平均（基准）:
   r_ens(i) = mean_m( rank(ŷ_{m,i}) )

2. 约束加权秩融合（内层 OOF 优化）:
   max_w ρ_s(y, Σ_m w_m·r_m) - λ·Σ_m w_m²
   s.t. w_m ≥ 0, Σ_m w_m = 1

3. 仅当加权在 ≥ 60% outer seeds 上优于等权时才部署
```

**先检查误差相关性**——若所有模型预测相关系数 > 0.95，融合无意义：

```bash
python scripts/tools/check_error_correlation.py \
  --oof-dir artifacts/phase3_v8/oof_predictions/ \
  --output artifacts/phase3_v8/error_corr.md
```

**步骤**:

```bash
# 生成严格 OOF 预测（inner CV）
python scripts/tools/generate_oof_predictions_v2.py \
  --targets rank_gaussian \
  --models RF,ET,SVR,GBR,XGB \
  --features mutation_only,mut_struct_wd,mut_struct_wd_ed \

  --output artifacts/phase3_v8/oof_predictions/

# 秩融合评估
```

### 4.2 实验 3B: 多 seed 模型 bagging

**目的**: 用不同训练随机种子拟合同一模型配置，部署时平均预测秩。降低单 seed 方差。

**设计**:

```python
# 训练阶段
for seed in range(1, 31):
    model = RF(n_estimators=500, random_state=seed)
    model.fit(X_train, y_train)

# 部署预测
for each model:
    pred_m = model.predict(X_new)
rank_final = mean([rank(pred_m) for each model])
```

**步骤**:

```bash
python scripts/tools/eval_seed_bagging.py \
  --targets rank_gaussian \
  --features mut_struct_wd_ed \
  --model RF \
  --bagging-seeds 30 \
  --outer-seeds 30 \
  --output artifacts/phase3_v8/seed_bagging.csv
```

**成功判定**: bagging 后跨 seed 标准差下降 ≥ 15%。

| 约束加权 | 0.390 ± 0.037 | -0.004 | 13/30 |

#### 4.3.3 发现

1. **融合均值 (0.390) 超越所有单模型**，但跨 seed 配对比较仍输给 oracle
2. **等权 = 约束加权** — 模型预测高度相关（~0.90+），多样性不足以通过优化权重获益
3. **XGB 意外成为最佳单模型**（不是 GBR），0.384 > 0.374
4. **SVR 显著落后** — 核方法在离散 one-hot 空间中不如树模型
5. **融合边际 ~+0.006** — 在 0.384 基础上推到 0.390

#### 4.3.4 v8 全部三阶段总结

```
v8 起点 (mutation_only + RF):           0.365 ± 0.008 (100-seed)
+ struct + wd (303d):                   0.383 (+0.018)
+ winsor_2.5 target:                    0.385 (+0.002, 边际)
+ MAE loss:                             0.387 (+0.002, 边际)
+ XGB (best single model):              0.384
+ 5-model equal-weight rank fusion:     0.390 (+0.006)
────────────────────────────────────────
v8 最终:                                0.390 ± 0.037 (30-seed)
vs v8 起点:                            +0.025 net gain
vs oracle bound (0.412):                剩余 gap 0.022
```

**结论**: v8 三阶段从 0.365 提升到 0.390，净增益 +0.025。剩余 0.022 gap 到 oracle bound 主要来自跨 seed 方差和模型误差相关性过高。

## 8. 判定标准与回滚机制

### 8.1 逐 Phase 接受标准

| Phase | 继续条件 | 回滚条件 |
|---|---|---|
| 1: 泄漏审计 | ED/筛选确认无泄漏或已修复 | 发现泄漏→废弃受影响的成绩 |
| 1: rank-target | ΔSp ≥ 0.005 或方差下降 | 无增益→保留 raw target |
| 2: 稳健回归 | ≥ 60% seeds 优于 MSE | 无增益→保留 MSE |
| 2: 稳定筛选 | Jaccard ≥ 0.5, ΔSp ≥ 0.005 | 不稳定→保留全特征 |
| 3: OOF 融合 | ΔSp ≥ 0.010 vs 最佳单模型 | 无增益→使用最佳单模型 |
| 3: seed bagging | 跨 seed σ 下降 ≥ 15% | 无改善→单 seed 部署 |
| 4: 100-seed 验证 | CI 不跨 0, cluster 不退化 | 退化→回滚至 mutation_only |
| 5: 标签审计 | 获得 SE 和异常样本表 | 无逐帧数据→跳过 |

### 8.2 版本化回滚

```
v_current (基线)
  ├── 数据哈希
  ├── 特征生成代码哈希
  ├── outer split 文件
  ├── 每 seed 指标
  └── 锁定测试预测

v_candidate (候选)
  ├── 与 v_current 相同 splits
  ├── 记录逐样本预测差异
  ├── 通过随机 + cluster 双验证
  └── 不达标→直接回滚至 v_current
```
