## 1. 一句话总览

我们严格复现并迁移了两篇论文的方法，结论是：

1. **论文的「序列编码器」对近同源适配体不适用**（transformer 仅 0.26），**但「深度集成」可迁移**（μ 0.32-0.36，接近 XGB）；
2. **主动学习 ≈ 随机**（三种代理一致），瓶颈是**标签噪声**而非采样；
3. **突破性发现**：现有数据里的 `dock`（对接分数）比 `gbsa`（MM-GBSA）**干净且好预测得多**（**0.547 vs 0.34**），且两者对 NUPACK 特征的反应**相反**。

## 2. 两篇论文的方法

| 论文 | 核心方法 | 本质 |
|---|---|---|
| **gkag145**（NAND 核糖开关深度批量贝叶斯优化） | 预训练 transformer（MLM+triplet）+ 深度集成 + UCB/Kriging Believer + DBTL 闭环 | 判别式：序列→功能回归 + 序列空间迭代选点 |
| **RaptGen**（生成式适配体发现） | VAE + profile HMM 解码器 → 低维潜空间 + GP-UCB 贝叶斯优化 | 生成式：序列→潜空间，潜空间里生成/优化 |

## 3. 复现与方法迁移效果

### 3.1 gkag145 复现（完整）

严格复现全部组件（代码在 `scripts/reproduction/`）：3-mer tokenizer、BERT 式 transformer（6 层/128 维/4 头/每头 64）、MLM+triplet 预训练、9×256 MLP 头 + 深度集成、UCB 分位数采集 + Kriging Believer。已对照论文 GitHub 源码（`Self-Organizing-Systems-TU-Darmstadt/NANDRiboswitchDesignByBayesOpt`）修正了位置编码（自定义余弦）和 triplet 负样本等细节。

### 3.2 迁移效果（诚实评估）

| 组件 | 效果 | 原因 |
|---|---|---|
| Transformer 序列编码器 | ❌ 0.123（异域语料）→ 0.261（同域突变语料） | 我们 13 位点近同源 vs 论文 60-70 位点 6 万条多样序列 |
| **深度集成** | ✅ μ 0.32-0.36（接近 XGB 0.40） | **唯一真正可迁移的部分** |
| UCB + KB + 主动学习 | ❌ AL ≈ random（3 种代理一致） | 见 §5 |
| 两阶段预训练（大语料） | ⚠️ 同域突变语料翻倍（0.12→0.26），但仍弱 | 序列多样性受限 |

**关键修正**：论文的 6.1 万条预训练语料是**四环素/新霉素核糖开关**（异域）。改用**我们序列的随机突变生成同域语料**（3 万条），融合从 0.12 提升到 0.26——证实了"语料域匹配"的重要性，但本任务最优载体仍是 XGB + one-hot。

### 3.3 RaptGen 理解（未复现）

RaptGen 解决"从 SELEX 数据生成全新适配体"，与我们"固定 141nt 骨架 13 位点优化"（4^13≈6700 万固定空间）本质不同。但其"**低维潜空间 BO**"思想有启发：我们的 13 位点空间已是低维离散空间，可直接用代理模型在其上排序选优。

## 4. gbsa 预测（0.34 → 0.40）

### 4.1 特征与最优结果

| 配置 | gbsa Spearman |
|---|---:|
| 303d 序列（one-hot + 窗口二聚 + 结构角色） | 0.384（30-seed） |
| 303d + NUPACK 7 有用块（192d）+ XGB 秩融合 | **0.399** |
| 预测级 18 块加权融合 | 0.399（权重坍缩=bagging） |

NUPACK 特征对 gbsa **稳定 +0.015**（28/30 seed 获胜），信号集中在 7 个有用块（contact_pca 折叠确定性、cluster_pair 长程配对、energy_land 等）。

### 4.2 标签噪声诊断（关键）

| 诊断量 | 值 |
|---|---|
| label 公式 | `0.961*Gap2 + 0.039*gbsa`（精确成立） |
| **sp(Gap2, gbsa)** | **0.065**（NUPACK 派生量与 MM-GBSA 几乎不相关） |
| sp(gbsa, MFE) | -0.068（gbsa 与 NUPACK 折叠能几乎不相关） |
| gbsa 占 label 方差 | 0.73% |
| **gbsa 分布** | std 10.4，max **+109** kcal/mol（物理不可能，25 个离群） |

**结论**：0.40 已是 oracle bound 0.412 的 97%，天花板是 **gbsa 标签噪声**（单条 MD 轨迹的 MM-GBSA 未收敛），不是模型/特征/采样。

### 4.3 新特征尝试（全部收窄）

| 新特征 | 结果 |
|---|---|
| Turner 堆叠能（定位 13 位点，52d） | -0.009（与 wd 冗余，不增反降） |
| 距离配体 SE(3) 不变量（PDB 3K1V） | ❌ 不可行（3K1V 是异源 34nt 序列） |
| 系综缺陷 vs WT | ⚠️ NUPACK 141nt mfe 异常慢（环境问题） |

## 5. 主动学习可行性（核心结论）

回顾式模拟（隐藏标签、模拟昂贵 oracle），**三种代理一致结论：AL ≈ random**：

| 代理 | μ 水平 | AL vs random |
|---|---|---|
| 弱 MLP（303d） | 0.19-0.25 | ≈ random |
| XGB 自助法（495d） | 0.20-0.29 | ≈ random |
| 深度集成 MLP+dropout（495d） | 0.32-0.36 | ≈ random（均值 0.321 vs 0.320） |

**为什么 AL 无效**：信号在**廉价的 NUPACK 物理特征**里、已被代理充分捕获；2000 条近同源序列覆盖盲区有限；gbsa 标签噪声（0.412）主导。**没有"信息缺口"让主动学习去填。**

**但要区分两个问题**：
- 主动学习**提升代理** → 不成立（≈ random）；
- 贝叶斯优化**找最优结合序列**（排序选优）→ 依然可行，只需代理可靠，不需要 AL 优于 random。

## 6. dock 预测（新突破，0.545）

### 6.1 dock vs gbsa 的本质区别

| 维度 | dock（r_i_docking_score） | gbsa（r_psp_MMGBSA_dG_Bind） |
|---|---|---|
| 本质 | 对接打分：**纯界面**（静态单构象，空间/氢键/静电/vdW 互补） | MM-GBSA：**界面 + 畸变能 + 溶剂化**（含分子内应变） |
| 是否含折叠应变 | ❌ 不含 | ✅ 含（适配体折叠到结合态的代价） |
| 生工团队判断 | 准确性较低 | 准确性较高 |
| **我们的测量** | **净**（std 1.05，全负，物理正确） | **噪**（std 10.4，+109 离群） |

文献佐证：MM-PBSA/GBSA 比对接分数"能提供更精确的排序"，其价值在于"**包括 distortion energies（畸变能）**"。

### 6.2 为什么 NUPACK 帮 gbsa 不帮 dock

- **gbsa 含分子内应变能**（折叠代价），由**二级结构**决定 → NUPACK（配对概率、折叠确定性）能捕捉 → 有帮助；
- **dock 是纯分子间界面打分**，由 3D 结合几何决定 → NUPACK 的 2D 结构是噪声 → 有害。

### 6.3 dock 预测结果（30-seed）

特征集对比（XGB）：

| 特征集 | dock Spearman |
|---|---:|
| **303d 序列** | **0.545** |
| 303d + NUPACK 有用块（192d） | 0.529（↓） |
| 303d + 全量 NUPACK（601d） | 0.514（↓↓） |
| 303d + 全量 NUPACK + 标签平滑 | 0.529 |

多模型秩融合（303d，30-seed）——可信度升级：

| 模型 | dock Spearman |
|---|---:|
| RF | 0.526 |
| ET | 0.521 |
| GBR | 0.534 |
| XGB | 0.545 |
| **四模型秩融合** | **0.547** |
| 秩融合 + 标签平滑 | 0.545 |

**结论**：① 四个模型一致给出 ~0.52-0.55，证明"dock 可预测"是稳健结论而非单模型偶然；② 秩融合 0.547 为最终数字（略优于单 XGB 0.545）；③ 标签平滑无额外增益（dock 本身已干净，无需去噪）。

**dock 和 gbsa 的特征需求完全相反**：NUPACK 对 dock 单调有害，对 gbsa 有益。dock 的最优配置是**纯序列 303d = 0.547（秩融合）**，显著高于 gbsa 的 0.34。

### 6.4 dock 能否修正 gbsa？（已实测否定）

| 尝试 | 结果 |
|---|---|
| dock 全局融合去噪 gbsa（z-score/秩平均/收缩） | 全部变差（0.21-0.30 vs 0.35） |
| 只用低分歧序列评估（诊断） | 无改善（0.344 vs 0.355） |
| dock 排序定向修正 gbsa（高分歧处替换） | 灾难性失败（0.054） |

**结论**：dock 和 gbsa 相关仅 0.289，本质是两个不同的量。dock 的低方差是"测的是另一个东西"（系统偏差），不是"干净"。用它修 gbsa 注入的是偏差。

## 7. 关键结论汇总

| 结论 | 说明 |
|---|---|
| 论文可迁移的是「深度集成」 | μ 0.32-0.36，接近 XGB |
| 论文不可迁移的是「序列编码器 + 主动学习」 | transformer 0.26（近同源）；AL ≈ random（标签噪声） |
| gbsa 天花板 = 标签噪声 | 0.40 已是 0.412 的 97% |
| **dock 是更干净更好预测的目标** | 0.547（四模型秩融合）vs gbsa 0.34，且只需 303d |
| dock 不能修正 gbsa | 两者是不同量（相关 0.289） |
| gbsa 去噪只能靠 MD 副本平均 | 唯一抬天花板路径，需生工团队 |

---

## 8. 下一步建议

1. **dock 方向**（重点推进）：dock 0.545 已是最优（303d），可进一步尝试秩融合/多模型融合，并把 dock 作为候选排序的干净信号；
2. **gbsa 方向**（保留）：去噪只能靠 **MD 副本平均**（5-15 条短轨迹，epsilon_in=4，igb=8），需生工团队；纯 ML 里 k-NN Hamming 标签平滑是唯一有效去噪（+0.021）；
3. **决策点**（生工团队）：`label = 0.961*Gap2 + 0.039*gbsa` 是否要朝 dock 或去噪后的 gbsa 重新加权；
4. **放弃方向**：主动学习提升模型、dock 修正 gbsa、3D 结构预测特征。
