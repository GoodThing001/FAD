# 论文改进方案（gkag145 → FAD/GBSA）

> 本目录保留 2026-09 的论文复现与研究过程。当前实施目标固定为独立 GBSA；旧主动学习比较存在实现缺陷，历史 `0.412` oracle bound 的估计方法未留痕。当前接口、候选生成、选样策略与 dock 修正复核统一以 [GBSA 总体方案](../项目记录/GBSA代理接口与候选闭环实施方案_20260930.md) 为准。

本文件夹记录我们基于论文 **《Iterative design of a NAND hybrid riboswitch by deep batch Bayesian optimization》**（NAR 2026, gkag145, TU Darmstadt）所做的方法复现与适配改进工作。

## 一句话定位

> 借鉴论文的「预训练序列编码器 + 深度集成 + 不确定性驱动批量选择」闭环范式，**不照搬**其输入、目标与采集函数，改造成适配本项目（RNA 适配体 → GBSA 昂贵标签）的**主动学习闭环**。

## 核心结论（速览）

1. **复现成功**：论文全部组件（3-mer tokenizer、BERT 式 transformer、MLM+triplet 预训练、深度集成、UCB+Kriging Believer）已在服务器 GPU 跑通，并严格对照论文 GitHub 代码（`Self-Organizing-Systems-TU-Darmstadt/NANDRiboswitchDesignByBayesOpt`）。
2. **正确实现下「序列+物理」≈ 0.40，不是 0.2**：303d 序列 + NUPACK 物理（加权）+ 强模型 XGB = **0.399**（30-seed），NUPACK 稳定 +0.015。早期 0.2 是三个实现缺陷（漏 NUPACK、弱 MLP、未选特征）。
3. **transformer 序列编码在本文本数据上偏弱**：论文靠 61,906 条无标注语料预训练，本项目仅 2000 条近同源序列，故 sequence-only 深度集成仅 0.123——是数据规模限制，非方法错误。
4. **特征加权选择已验证**：预测级块融合权重坍缩到均匀（块预测高度相关），但「平均 19 个相关模型」≈bagging 带来 +0.015；下一步用**可学习特征门控**做真正的特征级加权。
