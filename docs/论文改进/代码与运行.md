# 代码与运行

## 1. 代码位置

所有复现/适配代码在 [scripts/reproduction/](../../scripts/reproduction/)：

| 文件 | 内容 |
|---|---|
| `tokenizer.py` | 3-mer tokenizer（ACGU，69 词表：5 特殊 + 64 3-mer） |
| `encoder.py` | BERT 式 transformer encoder（复现论文超参） |
| `pretrain.py` | MLM + triplet 预训练（`mask_tokens`、`PretrainWrapper`、`pretrain`） |
| `surrogate.py` | 回归头（9×256 MLP）+ `DeepEnsemble` |
| `bo.py` | UCB/LCB 分位数采集 + Kriging Believer 批量 |
| `data.py` | FAD 数据加载 + tokenize/pad |
| `metrics.py` | Spearman / MAE / RMSE |
| `fusion.py` | 物理特征（303d 手工 + NUPACK）+ `FusedHead` / `FusedEnsemble` |
| `active.py` | 主动学习采集 + 批量选择（45+25+20+10） |
| `feature_weighting.py` | 特征加权选择（18 块 OOF 加权 + 反馈优化，FAD_env/xgboost） |
| `run_reproduce.py` | 复现驱动：预训练 → 集成 → 评估 →（可选）BO |
| `run_active.py` | 主动学习闭环驱动（AL vs random 学习曲线） |

## 3. 运行命令

```bash
# 冒烟测试（几秒，验证管线）
python -m scripts.reproduction.run_reproduce --smoke
python -m scripts.reproduction.run_active --smoke

# 正式复现（sequence-only 深度集成基线）
python -m scripts.reproduction.run_reproduce \
  --epochs-pretrain 30 --epochs-head 50 --n-ensemble 30 --batch-size 64

# 主动学习闭环（回顾式模拟，AL vs random）
python -m scripts.reproduction.run_active \
  --n-ensemble 20 --epochs-head 30 --epochs-pretrain 20 \
  --n-init 400 --n-holdout 400 --n-batch 100 --n-rounds 10
```

> 均从项目根目录以模块方式运行（`-m scripts.reproduction.xxx`）。服务器上用 `nohup env CUDA_VISIBLE_DEVICES=0/1 ... < /dev/null > log 2>&1 &` 后台执行。
