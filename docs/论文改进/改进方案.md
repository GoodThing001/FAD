# 改进方案：从论文 gkag145 到 FAD/GBSA 主动学习闭环

## 1. 论文方法回顾（gkag145）

论文目标：用深度批量贝叶斯优化迭代设计酵母中的 NAND 双输入杂交核糖开关（riboswitch）。

核心流水线：

```text
大量 riboswitch 序列
   ↓  自监督预训练（MLM + triplet）
预训练 transformer 序列编码器
   ↓  [CLS] 嵌入（128 维）
深度集成代理（n=100，MLP 头）
   ↓  μ(x) + σ(x)（预测 + 不确定性）
UCB 采集（分位数形式）+ Kriging Believer 批量
   ↓  每轮 16 条
in vivo 实验表征
   ↓  真实标签回流
重训代理 → 下一轮（DBTL 闭环）
```

### 各组件细节

| 组件 | 论文做法 |
|---|---|
| Tokenizer | DNABERT 式 3-mer（重叠，步长 1），`[CLS]`/`[SEP]`/`[PAD]` |
| Encoder | BERT 式：6 层，`d_model=128`，4 头，`d_attention=64`（=2·d_model/h），FFN 128→384→128，GELU，dropout 10%，自定义余弦位置编码（论文 GitHub 形式 `cos(π(i/(j+1)+(j+1)))`，非 Vaswani 正弦；代码见 `encoder.py`） |
| 预训练 | MLM（15% 掩码，80/10/10）+ triplet margin loss（硬负样本，margin=1.0），36 925 条序列 |
| 回归头 | 9×256 MLP，GELU，每 3 层 LayerNorm，无 dropout，输出 4 个配体状态表达量；损失为 Bernoulli KL 散度 |
| 集成 | n=100，随机初始化 + 仅 encoder 内 dropout 制造多样性 |
| 采集 | UCB 分位数形式 `u(x)=q_{1-α}(S(x))`；Kriging Believer 批量（选一条→用预测均值伪标签扩充→重训→选下一条）；候选池穷举 |

## 2. 我们复现了什么（忠实部分）

对论文方法做了**组件级忠实复现**，代码在 `scripts/reproduction/`：

| 论文组件 | 复现文件 | 说明 |
|---|---|---|
| 3-mer tokenizer | `tokenizer.py` | RNA 字母表 ACGU，64 个 3-mer + 5 个特殊 token，共 69 词表 |
| Transformer encoder | `encoder.py` | 完全按论文超参（6 层 / d=128 / 4 头 / d_attn=64 / FFN 384 / GELU / post-LN / dropout 0.1） |
| MLM + triplet | `pretrain.py` | 在线掩码 + 位置式单层 FFN 头 + 硬负样本 triplet |
| 回归头 + 集成 | `surrogate.py` | 9×256 MLP + DeepEnsemble（μ=均值，σ=成员标准差） |
| UCB + Kriging Believer | `bo.py` | 分位数 UCB/LCB + KB 批量 |

## 3. 我们改了什么（适配部分，依据 `../汇报/`）

论文面向「功能最优化」且输出是 4 个配体状态；本项目面向「GBSA 昂贵标签」且当前首要目标是**先提高代理模型泛化**，后期才转向低 GBSA 优化。因此做如下改造：

| 维度 | 论文 | 我们（适配后） | 理由 |
|---|---|---|---|
| 目标 | 4 个配体状态表达量 | 单一 GBSA（连续值） | GBSA 是 1 维连续标签 |
| 回归损失 | Bernoulli KL 散度 | MSE | KL 只适用于 [0,1] 概率型输出 |
| 输入 | 仅序列 | 序列嵌入 + 筛选后物理特征（Early Fusion 拼接） | 汇报：physics 提供序列之外的互补结构/能量信息 |
| 物理分支 | 无 | 手工 `mut/struct/wd`(303d) + NUPACK 有用子块(192d) | 项目已有特征；NUPACK 系综特征非序列直接可导出 |
| 集成规模 | n=100 | n=20~30 | 平衡成本与不确定性稳定性 |
| 采集函数 | 纯 UCB + KB | 不确定性 + 覆盖/新颖 + 有潜力 + 随机对照（100/轮） | 汇报：前期重「学准」，后期转 LCB/BO |
| 目标阶段 | 直接最大化 | AL（先学准）→ AL+BO → BO（找低 GBSA） | 汇报：连续过渡而非二选一 |

### 融合设计

```
RNA Sequence                     Physics（303d + 192d）
     ↓                                  ↓
Transformer Encoder（预训练冻结）    Spearman/MI 筛选 + 标准化
     ↓                                  ↓
[CLS] 嵌入 (128d)                   筛选后物理向量 (d_phy)
     └──────────────┬───────────────┘
                    ↓
           Early Fusion（concat，默认）
           （Gated Fusion 可选：gate 控制 physics 权重）
                    ↓
              FusedHead（MLP）
                    ↓
          DeepEnsemble → μ(x), σ(x)
```

对照实验约定（汇报 5.14）：`Sequence Only` vs `Physics Only` vs `Sequence+Physics`，融合需稳定优于 Sequence Only 才证明 physics 带来互补信息。

### 主动学习批量构成（每轮 100 条）

| 类型 | 数量 | 目的 |
|---|---:|---|
| 高认知不确定性（σ） | 45 | 解决模型最不会的区域 |
| 覆盖/新颖（物理空间最近邻距离） | 25 | 补足数据空间盲区 |
| 预测有潜力（低 μ） | 20 | 保留实际优化价值 |
| 随机对照 | 10 | 判断 AL 是否优于随机 |

physics-aware diversity 作为联合约束（当前用物理空间距离 + 去重近似，后续可升级为 farthest-point / DPP）。

### 停止标准（汇报 8.x）

预测平台期、不确定性饱和、AL ≈ Random、实验成本、转向 Optimization——核心判据是**新增昂贵标签的边际信息收益**，而非机械的固定 Spearman 阈值。

## 4. 与项目既有工作的关系

- 本工作**不是**继续堆模型去刷静态预测的 0.375 基线，而是把模型从「静态预测器」升级为「能决定下一批测谁的闭环」。
- 纯序列深度模型的低分（0.123）**印证了** PROJECT_STATUS 的决策：算法阶段的瓶颈不在模型复杂度，而在数据覆盖与标签质量。
- 深度集成在这里的价值是提供**可量化不确定性**（μ+σ），供主动学习采集使用，而非单纯提升点预测。
