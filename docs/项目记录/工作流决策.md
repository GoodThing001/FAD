## 当前流程

```text
canonical 2000序列
  → 13突变位点序列特征（mutation 52d + structure 43d + window-dimer 208d）
  → 每个外层随机划分内做目标裁尾、特征筛选、缩放和训练
  → RF / ET / GBR / XGB / SVR 单模型
  → 严格内层 OOF 预测与秩融合
  → 30-seed开发判断
  → 100-seed发布判断 + cluster split外推检查
  → 新候选先算 NUPACK Gap2，GBSA代理只修正最终标签的3.9%
  → 少量高价值候选进入昂贵 MD/MMGBSA 或实验验证
```

所有正式实验都必须通过 `scripts/run_experiment.py`，记录配置、数据SHA256、代码提交、环境、逐seed检查点、指标和完成标记。

## 当前唯一需要收尾的算法实验

运行修正后的30-seed嵌套特征选择，并与不筛选的303维对照做逐seed配对比较。mutation 52维必须强制保留。只有同时满足以下条件才晋级：

- 平均 `ΔSpearman ≥ 0.005`；
- 配对bootstrap 95% CI下界大于0；
- 至少60%的seeds优于全特征对照；
- cluster split不比对照下降超过0.01。

本地2-seed冒烟只能证明流程可运行，不能证明筛选有效。

## 路线决策

1. **暂不继续通用特征提取。** 已有303维序列特征足够作为主输入，新增高维特征大多产生冗余或噪声。
2. **先完成一次30-seed特征选择收尾。** 这是低于新MD计算成本的必要闭环，但只做预注册的少量筛选方法，不再穷举 wrapper/大网格。
3. **不要直接上更复杂的昂贵代理优化算法。** 在当前标签和2000样本上，经验上限约0.41；复杂优化器不能创造缺失的物理信息，还可能利用代理误差。
4. **下一项主投资应是标签质量与主动学习。** 先对50–100条诊断样本做逐帧GBSA收敛、协议和多replica审计；随后用不确定性+多样性选择小批新序列进行MD/MMGBSA，新增标签后再训练代理。
5. **候选生成阶段保留 NUPACK Gap2。** 它解释最终标签的主体；GBSA代理作为小权重修正和主动学习采集函数的一部分，而不是单独决定候选。

最终顺序是：`特征选择收尾 → 冻结当前代理 → GBSA标签审计 → 小批主动学习/MD → 扩充数据后重训`。
