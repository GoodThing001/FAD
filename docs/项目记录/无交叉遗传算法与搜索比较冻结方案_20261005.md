# 无交叉遗传算法与搜索比较冻结方案

2026-10-05；在正式 30/100 随机种子套件启动前保存。本文件冻结计算比较，不安排新 GBSA 计算，不选择主动学习。

## 1. 目标与边界

独立 GBSA（广义玻恩与溶剂可及表面积计算值）越低越好。主指标是同一个固定代理给新序列的**预测 GBSA 最小值**；它衡量优化器是否找到了代理上的低谷，不能证明真实 GBSA 更低。代理优化本轮暂停，固定两个诊断评分器：本地五成员自举梯度提升集成（命令名 `xgb`，本机实际为 scikit-learn 梯度提升后端）和随机森林（300 棵树）。均仅使用序列派生的 303 个特征、训练内筛选 100 个特征、训练标签 2.5%/97.5% 截尾。它们均不是已发布五模型排序融合，也不继承其 0.375 参考值。

## 2. 共同条件

- 数据：登记摘要一致的 2000 条规范序列；每种子取随机排列前 300 条训练，其余 1700 条只用于代理诊断，标签不参与搜索。
- 全部 2000 条从新候选中排除，但训练序列允许作为起点。
- 141 位骨架，仅 13 个既定位点可变；与参考序列不同的位点数限制 4–13。
- 每种子每代理只拟合一次，四种算法共享**同一个拟合指纹**。
- 起点共 16 个：8 个已标注优选起点与 8 个随机起点，按相同函数和随机数状态取得，核验顺序、序列与身份一致。
- 预算包含起点首次预测；缓存命中不计。每种子每代理每预算，按四算法中**实际唯一预测次数最小值**截取各自有序日志。预测最优值、多样性、训练距离、分布外比例均从同一截面计算。停止后的空余预算不补齐，也不混入下一算法的缓存。
- 所有算法最多 64 代；爬山的代数为所有路径累计接受的严格改善步数。

## 3. 四种算法和固定参数

| 算法 | 固定机制 |
| --- | --- |
| 同起点随机游走 | 从已评分历史序列均匀随机取父本，随机一位点变异；没有根据预测分数选择父本，也没有本策略的全局重启 |
| 多起点爬山 | 只考察未访问的一位点邻居，接受严格下降；预算不足随机抽取剩余邻居 |
| 束搜索 | 32 个父本上限、每父本 32 子代配额、80% 一位点、10% 全局重启；软距离 2；停滞 2 代停止 |
| 仅变异遗传算法 | 32 个种群上限，每代最多提出 128 子代；2 人锦标赛选择单父本；80% 一位点、其余二位点；10% 全局重启；2 个精英原样保留；软距离 2；停滞 4 代停止；**无交叉** |

遗传算法初始化仍是共同的 16 个起点，不免费补足 32 个个体。局部子代只有一个直接父本；全局重启没有父本。精英不重复预测。锦标赛抽样可重复，选择其中预测 GBSA 更低者；以确定的候选编号处理并列。软距离用于保留多样性，不保证所有幸存者都满足硬距离。

## 4. 运行计划与终点

1. 工程冒烟：901–902，预算 128，两代理，含重训稳定性及消融，共 44 子运行；只能验收可运行性。
2. 开发：401–430，预算 1024/4096/8192，两代理四算法；最低预算另做同训练集改变模型随机种子的重训稳定性、不同代理的重新排序，以及遗传算法三项预定义消融（锦标赛人数 1、4；全部一位点变异）。共 1140 子运行。
3. 确认：2001–2100，固定预算 1024，两代理四算法；共 800 子运行。保留开发时固定参数；不据确认结果调参。
4. 对接残差支线独立确认：3001–3100，沿用旧 30 种子代码的 3 折训练内折外残差与岭回归参数；只用序列预测 GBSA、预测对接辅助、已知实际对接辅助三组比较；不产生新对接或 GBSA。

对接支线启动前另固定三项**补充预筛诊断**：按外层测试区实际对接分数分别保留最低的 25%/50%/75%，仍以序列 GBSA 基础预测排序选择 20 条，报告相同 20 条标签预算下最低已知 GBSA 的配对差及真实 GBSA 最好 10% 的预筛保留率。三门槛同时报告，不根据测试标签挑选或反复调整；所有 400 条测试序列均假设已取得真实对接，因此成本、失败率和新候选可用性尚不能评估。

低预算确认用来检验四算法的基本取舍；高预算开发用来描述预测收益随计算量变化，**不**把高预算 30 种子结果当成 100 种子确认结论。不同预算重新运行，因提出批量会影响随机数消耗，不声称其搜索轨迹是同一运行的连续延长。

## 5. 统计、验收和可报告结论

配对差值定义为算法减同起点随机游走；更负代表找到更低预测值。胜/平/负的数值容差为10⁻¹⁰，搜索接受改善按严格下降；报告均值、配对种子自举 10000 次的 95% 区间、中位数和胜/平/负。主比较为遗传算法相对随机游走；相对爬山、束搜索及其他诊断为补充。区间为逐项区间，未校正多重比较。不同种子共享有限原始数据，因此不是 100 个独立生物学重复。

稳定性报告同训练集合、不同模型种子重跑后前 50 条集合的雅卡尔重叠（交集/并集），以及同一候选在重新拟合评分器和另一代理上的斯皮尔曼排序相关。模型间原始预测最小值不直接比较能量准确度。

每个子运行保留全量预测、单父本谱系、代际记录、候选分组、模型/训练标签/数据/骨架/配置指纹、停止原因及文件摘要。完整性要求计划子运行全部存在、无重复、有限值、预算未超、四算法起点完全相同、拟合指纹相同。未来回传验收只使用明确人工测试标签；真实 96 条旧批次保持原状态。

本阶段的终点是：代码与接口验收通过、冻结比较与支线确认完成、证据及总汇报可复核、实践指引完整。真实 GBSA 协议、预算及成熟代理到位后再启动新的验证决策；继续扩大算法/模型超参数网格不是本轮必做事项。
