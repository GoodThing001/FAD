# 模型卡：XGB 自举集成 GBSA 代理（发布候选用）

_2026-09-30；接口与策略详见 [GBSA 代理接口与候选闭环实施方案_20260930.md](GBSA代理接口与候选闭环实施方案_20260930.md) 与 [候选闭环框架_20260930.md](../论文改进/候选闭环框架_20260930.md)。_

## 1. 身份

| 字段 | 值 |
|---|---|
| `model_id` | `xgb_boot{n}_xgboost`（服务器，n=成员数）／`xgb_boot{n}_sklearn_gbm`（本地无 xgboost 回退；**不得**把本地回退结果当作服务器后端成绩） |
| `feature_version` | `seq303_screen100`：303 维序列特征（3-mer 位点编码），每轮**训练折内**筛到 top-100 |
| `INTERFACE_VERSION` | 0.2.0（`fit(sequences, y_gbsa)` / `predict(sequences) → Prediction`） |
| 目标 | 独立 `gbsa`（MM-GBSA，越小越强） |
| 不确定度 | `sigma = ensemble_spread_uncalibrated`（成员标准差，**未校准**；启用 LCB/uncertainty 采集前必须先验证 σ 与误差/命中分层相关） |
| 训练规模 | 由闭环决定：`n_init`（300/400）+ 每轮新揭示标签；逐轮训练集只含当轮已揭示真值 |

## 2. 输入/输出与禁止项

- 输入：141 nt 序列（仅 13 个可变位点，其余必须等于 WT；`validate_sequences(check_scaffold=True)`）。
- 输出：`pred_gbsa`（GBSA 尺度）；`sigma` 可选（见上）。
- **禁止作为输入**：`label`、`total_energy_change`、`r_psp_MMGBSA_dG_Bind`、`dock`、`gbsa`、`Gap1/2/3`（泄漏清单见实施方案 §3）。特征筛选只在训练折内完成。

## 4. 与历史模型的关系（必须分清）

- **不是 v8 秩融合**：v8 的 100-seed Spearman 0.375 是静态五模型秩融合的成绩，**不能**贴到本模型或任何选样曲线上。
- `ReleaseFusionSurrogate`（五模型原始预测均值）同样**不是** v8 秩融合，其 `model_id=release_five_model_mean_v1` 单独标识。

## 5. 使用范围与限制

- 用途：闭环内的候选打分/选样（回顾式与前瞻式导出），前瞻式批次停在 `PARKED`。
- 限制：
  1. 结论只在**代理表**（2000 条，`n_from_wt` 4–13 的壳）内可复算；生成候选超出该壳（如 1–5 突变）时预测是外推，OOD 标记与分层误差须随批次报告；
  2. σ 未校准，不能当概率/置信区间使用；
  3. 训练/查询后端必须核对 `model_id`（本地 sklearn 回退 ≠ 服务器 xgboost）；
  4. 每次运行由 `fingerprint.json`/`run_manifest.json` 记录数据哈希与源码哈希，跨版本对比须先对齐指纹。
