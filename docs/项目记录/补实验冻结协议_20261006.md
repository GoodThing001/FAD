# 2026-10-06 补实验冻结协议

本文在本轮模型结果产生前保存。所有目标为独立 GBSA；不使用加权 label，不读取父目录遗留代码或数据作为运行输入。

## 1. 历史配方与配对消融

历史固定划分：当前主线 train+val 的 1800 条序列训练，test 的 200 条测试，按序列关联到登记的完整数据。历史模型：ExtraTrees（极端随机树）200 棵、max_features=log2、min_samples_leaf=5、random_state=42；训练集内筛前 100 个重要特征，再用 GradientBoostingRegressor（梯度提升回归）500 棵、深度3、叶最少3、学习率0.03、random_state=42。按列标准化仅拟合训练集；不裁剪标签。不同特征组分别标准化与合并后按列标准化数学等价。

配方固定为五组：52 维突变独热；303 维序列特征；303+14突变类型+169同碱基指示=486维；303+601直接NUPACK=904维；完整1087维。169维是13×13独热内积，不能称完整碱基交互编码。

开发：11001–11030，每次1800/200划分。确认：12001–12100，独立100个划分种子，同样五组、同样训练预算。主比较1087对303；486对303用于检查交互/突变类型，1087对904用于检查该额外分支，904对303检查NUPACK增量。配对 Spearman 差值、20,000次种子自助法置信区间、胜平负；MAE与RMSE辅助。固定42只作重放，不能从其上再挑参数。保存所有预测和特征索引。固定划分曾被历史优化反复使用，重放不能恢复独立测试资格。

## 2. 修正结构缺陷

NUPACK4，RNA、30℃、默认stacking模型。目标结构为野生型最小自由能结构。未配对概率读取矩阵对角线；全局缺陷是错误配对/未配对的期望核苷酸数（0–141）。前20条对照官方normalized defect（归一化结构缺陷）×141，允许浮点误差1e−5；这是[官方接口定义](https://docs.nupack.org/utilities/)。目标结构中存在不允许的碱基配对时，其概率定义为0并明确标为invalid_target_pair；其余异常记录错误并终止正式计算，禁止捕获异常后静默置0。目标结构可行不代表真实结合构象正确。

2000条重新计算，不覆盖历史CSV。对无泄漏303维基线比较加缺陷、加结构概率、两者，30个配对种子11001–11030，1600/400划分，与历史495维探索实验分开。模型、筛选和其他处理与第一节相同，不把历史全数据选出的192维“有用”特征当正式输入。

### 2.1 官方接口验收修订（特征比较产生结果前）

首个服务器重算已完成2000条配对矩阵，但官方`defect`核验首条时因目标不兼容报`Space::clone`并记为FAILED。定向诊断和所装源码确认：4.0.0.27的`defect`借用设计约束求解器，目标中存在非允许碱基配对时无法接受固定序列；配对概率矩阵仍可定义该目标的期望错误核苷酸数。不能捕获这个异常后虚构官方通过。

新运行另编号v2，GBSA标签及模型配方不变，完整重算。官方核验改为：对全部兼容WT目标的条目（诊断发现4条）比较原特征；对前20条分别以全未配对目标和其自身MFE目标核对公式（另40个诊断），容差仍1e−5。不同诊断目标仅用于核验公式，不进入训练特征；全部2000条特征目标仍为WT。未兼容的WT目标无法逐条获得该版本官方utility的直接核验，如实保留这个边界。失败包、诊断源码和结果均保存，不覆盖。

### 2.2 筛选后解释性消融（明确属于结果后提出）

首轮正确特征比较发现：缺陷只在4/30划分进入前100，概率在0/30划分进入，因此该结果只能评价当前筛选管线，不能等同新特征被30次直接使用后的效应。追加一次固定的强制保留诊断：同30种子、同1600/400、同GBR500，基线前100与强制缺陷、强制概率、强制两者四臂；每臂总输入数仍100，从训练重要度排序中保留99或98列，再补入强制列。不看测试标签筛列，不改目标/模型参数，不搜权重。它是在已见首轮结果后提出的机制诊断，不冒充预注册确认；无论结果正负都完整报告，不以此直接晋级发布主线。

## 3. 论文迁移控制

固定外层30种子11001–11030、1600/400。同一个3-mer编码器结构、同一GBSA回归头配置、相同监督训练次数，比较无预训练、原论文外域语料预训练、仅训练序列生成的域内变体预训练。域内语料排除全部2000条已知序列，避免生成与holdout相同的序列；生成父本仅来自外层训练集。预训练语料最多2000条、5个epoch；回归为10个独立9层×256头，50个epoch。此预算作为受控开发比较，不能替代旧30epoch/30头或原论文完整计算预算。全部训练种子显式设置。三臂冻结相同初始编码器种子13000；独立外域语料预训练一次后复用，域内按外层划分分别预训练；固定回归头批次128，预训练批次32。补充同划分303维GBR（500棵、深度3、叶最少3、学习率0.03、不筛选）经典对照，不作为预训练效应的一部分。晋级条件：域内臂相对无预训练、外域和经典对照的Spearman差值95%区间均大于0，才追加冻结100种子确认，否则保持开发证据。外域语料缺失则该臂标为缺失，不使用随机序列冒充。

### 3.1 执行调度记录（不改变第三节科学配方）

外域语料来源边界：实际读取历史服务器保留的data/ngs_sequences.txt，来源文件与使用子集均记录哈希；本轮未从原论文测序数据库重新下载并逐条认证完整原始语料。第三节“原论文外域语料”沿用历史文件归属描述，正式新结果采用“历史外域语料”名称，不能仅凭文件名证明完整原论文来源。这一核查只收窄来源声明，不替换实验使用的文件或条目。

首个30种子串行预训练运行耗时较长，停止其单个实验子进程并保留部分产物为FAILED，不将该包并入正式统计。重新用相同脚本、参数、初始权重种子和30个外层种子分四组执行：11001–11008、11009–11016、11017–11023、11024–11030；每组独立主运行器验收DONE，最多四个进程、每进程两个CPU线程，两组分配每张GPU。外域预训练改为每组执行一次并在组内复用（四组相同语料、初始权重、种子及训练次数）；这是额外调度成本，不增加每个受比较模型的训练次数。聚合入口要求四组DONE、数据和实际模型源码哈希一致、无重复/缺失种子、全部120行和对应文件齐全，再由主运行器写聚合DONE。GPU浮点运行不承诺跨设备逐位一致，所有实际预测均保存并独立复算。

## 4. 修正主动学习

回顾式固定池，holdout400不用于训练，初始标签400、候选池1200，每轮100，共5轮至900。每个外层种子共享初始点、候选池、holdout。使用同一303维特征和5成员bootstrap直方图梯度提升集成（200轮、深度3、学习率0.03、叶最少20、L2=1；结果产生前为降低计算成本将实现固定为HistGradientBoostingRegressor），每轮仅已揭示标签拟合，标准化只拟合已标注数据；ensemble sigma仅为未校准的成员分歧。

四臂：random均匀随机；greedy预测GBSA最低；uncertainty成员分歧最高；mixed按45%分歧、25%覆盖、20%预测最低、10%随机逐项去重并按不足补足。覆盖距离使用训练数据拟合的同一标准化坐标，逐次最远点增加多样性。报告固定holdout Spearman/MAE/RMSE与未包含共享初始集的查询最优GBSA、候选池遗憾值、top10%召回。开发30种子11001–11030；确认100种子12001–12100；不能用发现好序列推断模型学习更快。所有揭示来自表内已有GBSA，新增真实测量数为0。

确认运行的覆盖距离按32个候选一组计算，减少三维临时数组占用；保留原float32按特征轴求和及候选顺序，没有改变算法或模型参数。独立冻结入口为 `supplement_active_bounded_20261006.py`，有与完整数组实现相同选点的针对性测试；开发运行入口保持原文件，避免改变运行中的源码。

## 5. 实体计算边界

新序列真实 docking 与 GBSA 的成本、失败率及搜索算法真值优势，需要可用结构生成/对接/MD协议、统一QC与真实预算。本轮只检查现有资源；没有协议和预算不启动新MD，也不使用历史96条文件。本轮计算补实验不能填补真实候选的真值空缺。
