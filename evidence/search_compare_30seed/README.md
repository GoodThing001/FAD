## 3. 判读（限代理表计算诊断；阶段 C 才涉及真实 GBSA）

1. 引导式策略原始 `best_pred` 低约 4.8，30/30 seeds 一致，但这是**不同实际预测次数、不同起点**下的代理输出，只说明各运行找到了较低预测值，不构成公平算法比较或发现效果证据。
2. 爬山与束的原始 `best_pred` 差 CI 跨 0、中位数 0、20/30 平局；实际预测次数也不同。阶段 C 的策略尚未定案，应先读同起点、按实际预测次数对齐的比较，再由真实 GBSA 多独立批次判定。
3. **主要风险信号：排序不稳定**。top-50 的跨模型 Spearman 仅 0.18–0.30（随机基线也只有 0.27–0.30——这是代理细粒度排序的固有噪声）；换代理种子重跑后，爬山/束的 top-50 名单重叠仅 2.9% / 3.7%。即：引导式搜索找到的"最低预测候选"及其具体名单对代理重训高度敏感，最优点附近主要由噪声驱动（方案 R7 类风险的直接量化）。OOD 集中风险未出现（引导式 top-50 OOD≈0）。
4. **按方案 §5 门槛的下一步**：在投入真实 GBSA 预算前，优先改善代理与标注（σ 校准/去噪），并接受"搜索给出的是一组预测优选候选而非可靠排序"的定位；阶段 C 的实测终点、对照份额与协议须先预注册再签批次。
